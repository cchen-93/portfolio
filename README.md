## 一、專案名稱

猜撲克牌花色及號碼遊戲

開發語言：

* Python 3

程式檔案：

```
guess_poker.py
```

說明文件：

```
README.md
```

---

# 二、專案目的

本程式設計一個互動式猜牌遊戲。

透過 Python 的：

* 隨機產生
* 條件判斷
* 迴圈控制
* 函式設計
* 例外處理

製作一個完整的終端機遊戲。

玩家需要：

1. 猜測撲克牌花色
2. 花色正確後猜測點數
3. 直到猜中為止

---

# 三、遊戲規則

## 1. 系統產生答案

程式會隨機產生：

* 一種花色
* 一個點數

例如：

```
梅花 8
```

此答案會隱藏，等待玩家猜測。

---

## 2. 猜花色階段

玩家選擇：

```
1. 黑桃
2. 紅心
3. 方塊
4. 梅花
```

如果錯誤：

```
❌ 花色錯誤，請再試一次
```

如果正確：

```
🎉 花色猜對了！
```

進入下一階段。

---

## 3. 猜數字階段

玩家輸入：

```
1 ~ 13
```

對應：

| 數字   | 牌面 |
| ---- | -- |
| 1    | A  |
| 2~10 | 數字 |
| 11   | J  |
| 12   | Q  |
| 13   | K  |

---

猜錯時：

如果玩家輸入較小：

```
⬆️ 答案比目前數字大
```

如果玩家輸入較大：

```
⬇️ 答案比目前數字小
```

直到猜中。

---

# 四、程式流程設計

程式流程如下：

```
開始
 │
 ▼
隨機產生撲克牌
 │
 ▼
玩家猜花色
 │

 │     │
 │     ▼
 │   繼續猜花色
 │
 └──正確
        │
        ▼

        │
        ├──錯誤
        │
        ▼
     提供大小提示
        │
        ▼
     繼續猜數字
        │
        ▼
      猜中
        │
        ▼
      結束
```

# 五、程式架構說明

程式主要分成四個部分：

---

## 1. 常數設定區

負責管理固定資料。

例如花色：

```python
SUITS = {
    "1":"黑桃",
    "2":"紅心",
    "3":"方塊",
    "4":"梅花"
}
```

優點：

* 避免重複輸入
* 增加程式可讀性
* 未來容易修改

---

## 2. 工具函式區

包含：

### card_name()

功能：

將數字轉換成牌面。

例如：

```python
11 → J
12 → Q
13 → K
```

---

### generate_card()

功能：

隨機產生一張牌。

使用：

```python
random.choice()
random.randint()
```

產生：

```
花色 + 點數
```

---

## 3. 輸入處理函式

包含：

---

### get_suit()

功能：

取得玩家猜測花色。

處理：

* 正確輸入
* 錯誤輸入
* Q 離開

---

### get_number()

功能：

取得玩家猜測數字。

包含：

數字驗證：

```python
1 <= number <= 13
```

避免輸入：

```
0
20
abc
```

造成錯誤。

# 六、主要程式邏輯說明

## 第一階段：猜花色

程式使用：

```python
while True:
```

讓玩家持續猜測。

判斷：

```python
if user_suit == target_suit:
```

如果相同：

進入下一階段。

---

## 第二階段：猜數字

同樣使用：

```python
while True:
```

直到猜中。

判斷：

小於答案：

```python
user_number < target_number
```

顯示：

```
答案比較大
```

大於答案：

```python
user_number > target_number
```

顯示：

```
答案比較小
```
